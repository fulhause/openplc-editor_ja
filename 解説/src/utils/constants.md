# src/utils/constants.ts の解説

1. `export const CONSTANTS = {`
   - さまざまな定数をまとめたオブジェクト `CONSTANTS` をエクスポートします。
2. `theme: { variants: { LIGHT: 'light', DARK: 'dark' } }`
   - テーマに関する定数。ライトとダークの文字列を定義しています。
3. `paths: { MAIN: '/', PROJECT: 'project', EDITOR: 'editor', RES: 'resource' }`
   - アプリ内で使うパス名の定数です。
4. `types: { PROGRAM: 'program', FUNCTION: 'function', FUNCTION_BLOCK: 'functionBlock' }`
   - プログラムの種類を表す文字列を定義します。
5. `languages: { IL: 'IL', ST: 'ST', LD: 'LD', FBD: 'FBD', SFC: 'SFC' }`
   - 対応しているPLC言語の略称を定義しています。
6. `}`
   - `CONSTANTS` オブジェクトの終わりです。
